# Agrifusion Net

**Hybrid EfficientNetV2-S + Transformer for rice leaf disease image classification, with Flask-based farmer advisory support.**

This is a complete starter project for academic/research use. It includes a trainable image classifier, held-out test evaluation, and a Flask interface. It does **not** ship with a dataset or a trained checkpoint: those must be supplied/generated by running the steps below. No accuracy is claimed until you train and evaluate it on your chosen dataset.

## 1. How the system works

1. A rice-leaf image is resized and normalized.
2. EfficientNetV2-S extracts a spatial feature map. ImageNet weights are optional (`--pretrained`).
3. The spatial feature map is converted into tokens and passed through Transformer encoder layers to model relationships between image regions.
4. A classification head returns class scores. The application shows the top label and relative softmax scores.
5. `advisory.json` provides general, editable next-step guidance based on the predicted label.

**Important:** the advice is a rule-based demonstration, not a second trained language model. Predictions can be wrong due to lighting, backgrounds, dataset bias, similar symptoms, or unfamiliar disease classes. Confirm field conditions with a local agricultural extension officer. Follow local pesticide labels and regulations.

## 3. Environment setup

Python 3.10 or 3.11 is recommended. A GPU is helpful but not required; CPU training may be slow.

### Windows PowerShell

```powershell
cd agrifusion_net
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

### macOS/Linux

```bash
cd agrifusion_net
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If the PyTorch/torchvision installation fails, install a compatible pair from the official PyTorch installation selector, then run `pip install -r requirements.txt` again.

## 4. Get and organize a dataset

Find a rice leaf disease image dataset from a reputable source, for example the [Kaggle dataset search for rice leaf disease](https://www.kaggle.com/datasets?search=rice%20leaf%20disease). Check its license, citation requirements, class definitions, and whether images are from independent plants/fields. Do not assume every dataset has the same classes.

Arrange images in **class subfolders** as follows. Folder names become model labels:

```text
data/rice_leaf_disease/
├── train/
│   ├── bacterial_blight/
│   ├── brown_spot/
│   ├── healthy/
│   └── leaf_smut/
├── val/
│   ├── bacterial_blight/
│   ├── brown_spot/
│   ├── healthy/
│   └── leaf_smut/
└── test/
    ├── bacterial_blight/
    ├── brown_spot/
    ├── healthy/
    └── leaf_smut/
```

The four names above are examples only. **Use the exact class names in your selected dataset** in all three splits. If your dataset contains rice blast or other classes instead, create those folders accordingly. Each split must contain at least two class folders and each class should have images. `train` and `val` are required for training; `test` is required for final evaluation.

Suggested split: 70% train, 15% validation, 15% test, stratified by class. Keep the test set untouched until model selection is finished. Avoid leakage: near-duplicate images or images of the same leaf/plant should not appear across splits. If the dataset already provides splits, inspect and preserve them. Resize/augmentation is handled in code; do not put augmented copies of a test image in training.

## 5. Train the model

From the project directory:

```bash
python train.py --data data/rice_leaf_disease --epochs 15 --batch-size 16 --lr 0.0001
```

For ImageNet-pretrained EfficientNetV2-S (downloads weights the first time; internet required on first run):

```bash
python train.py --data data/rice_leaf_disease --epochs 15 --batch-size 16 --lr 0.0001 --pretrained
```

The script automatically selects CUDA when available. If you run out of memory, reduce `--batch-size` to `8` or `4`. The best checkpoint based on validation accuracy is saved to `artifacts/agrifusion_net.pt`; epoch history is saved to `artifacts/training_history.json`. Do not report validation accuracy as test accuracy.

## 6. Evaluate on the held-out test set

```bash
python evaluate.py --data data/rice_leaf_disease --checkpoint artifacts/agrifusion_net.pt
```

This writes `artifacts/evaluation.json` and prints accuracy, macro F1, per-class precision/recall/F1, and a confusion matrix. In your report, include the actual output from your own run, dataset size and source, class counts, hardware, epochs, and split method. If you change dataset class folders after training, retrain the model.

## 7. Run the Flask application

After training:

```bash
python app.py
```

Open <http://127.0.0.1:5000> in your browser and upload a clear JPG/PNG leaf image. Stop the server with `Ctrl+C`. The app looks for `artifacts/agrifusion_net.pt`. To use another checkpoint, set `AGRIFUSION_CHECKPOINT` before launching.

PowerShell example:

```powershell
$env:AGRIFUSION_CHECKPOINT="artifacts/agrifusion_net.pt"
python app.py
```

The app limits uploads to 10 MB and is configured for local use. Do not expose it publicly without production hardening, authentication/rate limiting where appropriate, secure hosting, and a review of privacy and agricultural-safety requirements.

## 8. Troubleshooting

- **“No trained checkpoint found”**: complete training first; confirm `artifacts/agrifusion_net.pt` exists.
- **Class folders differ**: `train`, `val`, and `test` folder names must match exactly.
- **Out of memory**: reduce batch size; try CPU if necessary.
- **Poor results**: inspect class balance and label quality, obtain more diverse field images, verify splits, and compare with a simple baseline. More epochs do not guarantee better generalization.
- **Pretrained download fails**: omit `--pretrained` or resolve the internet/cache issue and retry.
- **Unsupported image**: use JPG or PNG.

## 9. Academic integrity and limitations

- No dataset, checkpoint, or measured performance is bundled.
- Report results only after running the code. Do not invent accuracy or claim superiority without experiments.
- The softmax score is not a calibrated disease probability.
- Dataset performance may not transfer to different cultivars, regions, cameras, weather, or field backgrounds.
- Advisory entries are general suggestions, not crop-specific prescriptions. Obtain local expert confirmation before treatment.
- Cite the dataset and its license, and cite EfficientNetV2 / Transformer sources in the final submission.
